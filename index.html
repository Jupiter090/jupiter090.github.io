My journey so far...

My journey began in my childhood. I was really intrested in computers and how they work since I've been a kid. And that curiosity just grew and grew over the year, until the year 2020, when I saw a tutorial on youtube on how to code in C#. It was something that I always wanted to try so I wasted no time and got right into it, but at first I wasn't actually learning anything, just copying tutorials and because of that I gave up on coding. But after a few months I discovered this mobile app, which was able to teach me how to make websites and I downloaded it right away. It took me a bit of time but eventually I was able to finish every lesson in that app and made my first website. It wasn't anything spectacular, but I was proud of myself because I just made something built completly by me with no help of tutorials. After this acheivement I made the step to try and learn C# again, but this time actually trying to understand what each thing meant. And it paid off, I was able to make projects by myself. Afterwards I experimented a bit with C# like console applications, web app with C# backend, windows forms apps, but eventually I landed on Unity where I spent most of my time. I've been learning Unity ever since and already finished a few smaller games, which you will be able to see at the projects page so go chek it out :). Alongside learning C# and Unity I also tried other languages like Python or Java, but I haven't reached a level where I would be able to make what is considred by me a 'good code'.
